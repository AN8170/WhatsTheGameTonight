# 🏈 WhatsTheGameTonight?

Your daily guide to college football.

WhatsTheGameTonight? is a free, mobile-friendly college football schedule website that makes it easy to find out who's playing, when games start, and which teams are facing off.

Whether you're planning your Saturday around college football or looking for a matchup during the week, WhatsTheGameTonight? helps you stay on top of the action.

🏟️ Features

Today's Games: Automatically displays college football games scheduled for the current day.

Game Schedules: View upcoming matchups and kickoff times.

Live Scores: See game scores and results when available.

Date Selection: Browse games scheduled for different dates.

Team Search: Quickly find games involving your favorite college football teams.

Conference Filters: Filter games by conference.

Central Time Display: Kickoff times are displayed in Central Time.

Mobile-Friendly Design: Responsive layout that works on phones, tablets, and desktop computers.

Automatic Data Retrieval: Uses ESPN's publicly available college football data feed.

🚀 How to Use

Open the WhatsTheGameTonight? website.

View the college football games scheduled for today.

Select another date to browse upcoming or previous games.

Search for your favorite team or use the conference filters.

Check kickoff times and scores when available.

No account or subscription required!
